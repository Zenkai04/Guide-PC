# Périphériques et connectique

## 1. Objet

Ce document définit les règles de sélection des périphériques et des interfaces de connexion.

Les périphériques constituent les interfaces entre le système informatique et son environnement.

Ils permettent :

* les entrées utilisateur ;
* les sorties d'information ;
* les échanges de données ;
* la communication avec d'autres systèmes ;
* l'extension des capacités du système.

Leur sélection influence directement :

* l'ergonomie ;
* la productivité ;
* l'expérience utilisateur ;
* l'interopérabilité ;
* la capacité d'évolution du système.

Toutes les règles générales du guide restent applicables.

---

# 2. Mission

La mission des périphériques est de permettre les échanges d'informations, de données et de commandes entre le système informatique et les utilisateurs ou équipements externes.

Les périphériques ne créent généralement ni calcul, ni mémoire, ni stockage principal.

Ils rendent les ressources du système accessibles et exploitables.

---

# 3. Ressources fournies

## Entrées

Capacité à transmettre des informations vers le système.

Exemples :

* clavier ;
* souris ;
* tablette graphique ;
* scanner ;
* webcam ;
* microphone ;
* manette ;
* capteurs.

---

## Sorties

Capacité à restituer des informations.

Exemples :

* écran ;
* imprimante ;
* haut-parleurs ;
* casque ;
* dispositifs haptiques.

---

## Communication

Capacité à échanger des données.

Exemples :

* USB ;
* Thunderbolt ;
* Ethernet ;
* Wi-Fi ;
* Bluetooth ;
* lecteurs de cartes.

---

## Stockage externe

Connexion de supports amovibles :

* SSD externes ;
* HDD ;
* clés USB ;
* cartes mémoire.

---

## Extensions

Connexion de matériels spécialisés :

* interfaces audio ;
* cartes d'acquisition ;
* stations d'accueil ;
* GPU externes lorsque compatibles.

---

# 4. Capacités offertes

Les périphériques peuvent permettre notamment :

* la saisie de données ;
* la restitution audio ;
* la visioconférence ;
* le travail collaboratif ;
* la sauvegarde externe ;
* le développement logiciel ;
* la création graphique ;
* la production musicale ;
* les jeux vidéo ;
* le contrôle d'équipements industriels.

Ces capacités dépendent autant des périphériques eux-mêmes que des interfaces disponibles.

---

# 5. Caractéristiques constructeur

Les informations suivantes doivent être collectées.

## Interface

* USB ;
* USB-C ;
* Thunderbolt ;
* HDMI ;
* DisplayPort ;
* Ethernet ;
* Bluetooth ;
* Wi-Fi.

---

## Débit

* bande passante maximale ;
* vitesse réelle lorsque disponible.

---

## Compatibilité

* systèmes d'exploitation ;
* pilotes ;
* protocoles.

---

## Ergonomie

* dimensions ;
* poids ;
* disposition ;
* réglages.

---

## Fiabilité

* durée de vie annoncée ;
* indice IP lorsque pertinent ;
* robustesse mécanique.

---

# 6. Critères éliminatoires

Un périphérique est rejeté immédiatement si :

## Compatibilité

* interface absente ;
* pilote indisponible ;
* protocole incompatible.

---

## Fonctionnalité

* fonction indispensable absente.

---

## Contraintes

* coût supérieur au budget sans justification ;
* indisponibilité.

---

# 7. Vérifications

Le moteur vérifie notamment :

## Compatibilité physique

* connecteurs ;
* alimentation éventuelle.

---

## Compatibilité logicielle

* pilotes ;
* firmware ;
* système d'exploitation.

---

## Compatibilité fonctionnelle

* protocole ;
* normes ;
* logiciels utilisés.

---

## Compatibilité environnementale

* longueur des câbles ;
* portée sans fil ;
* conditions d'utilisation.

---

# 8. Mesures exploitables

Les mesures doivent être adaptées au type de périphérique.

## Communication

* débit réel ;
* latence ;
* stabilité de la connexion.

---

## Ergonomie

* confort ;
* précision ;
* fatigue d'utilisation.

---

## Audio

* réponse en fréquence ;
* niveau de bruit ;
* latence.

---

## Vidéo

* résolution ;
* fréquence ;
* qualité d'image.

---

## Fiabilité

* taux de panne ;
* endurance des connecteurs.

---

# 9. Métriques

Le moteur peut calculer notamment :

## Communication

* coût par Gb/s ;
* latence par euro.

---

## Ergonomie

* indice de confort ;
* productivité estimée.

---

## Long terme

* indice d'interopérabilité ;
* indice de maintenabilité ;
* indice de robustesse ;
* indice de réutilisation.

---

# 10. Interactions

Les périphériques interagissent principalement avec :

## Carte mère

* interfaces disponibles ;
* contrôleurs.

---

## Système d'exploitation

* pilotes ;
* gestion des périphériques.

---

## Utilisateur

* ergonomie ;
* habitudes d'utilisation ;
* accessibilité.

---

## Réseau

* communications externes ;
* partage de ressources.

---

# 11. Critères de décision

Les périphériques sont sélectionnés selon :

1. adéquation à la mission ;
2. compatibilité ;
3. ergonomie ;
4. fiabilité ;
5. interopérabilité ;
6. évolutivité ;
7. coût.

Le moteur privilégie les périphériques qui améliorent réellement l'efficacité de l'utilisateur et l'intégration du système dans son environnement.

---

# 12. Durée de vie

Le moteur évalue notamment :

* durée de vie mécanique ;
* disponibilité des pilotes ;
* pérennité des interfaces ;
* facilité de remplacement ;
* compatibilité avec les évolutions futures.

---

# 13. Risques

Les principaux risques sont :

* obsolescence des interfaces ;
* dépendance à des pilotes propriétaires ;
* incompatibilités logicielles ;
* usure mécanique ;
* défaillance des connecteurs ;
* limitation des débits.

Chaque risque doit être documenté.

---

# 14. Rapport de décision

Le rapport final doit expliquer :

* pourquoi ces périphériques ont été retenus ;
* comment ils répondent aux besoins de la mission ;
* quelles interfaces sont utilisées ;
* quelles possibilités d'évolution existent ;
* quelles limites subsistent ;
* quelles mesures ont été utilisées ;
* quelles métriques ont été calculées ;
* quelles hypothèses ont été retenues.

La décision doit être entièrement traçable et reproductible.
