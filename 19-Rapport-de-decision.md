# Rapport de décision

## 1. Objet

Ce document définit la structure et le contenu du rapport produit par le moteur de décision.

Le rapport constitue la restitution finale de l'analyse.

Son objectif est de présenter une recommandation claire, argumentée, traçable et reproductible.

Le rapport ne se limite pas à annoncer une configuration.

Il explique le raisonnement ayant conduit à cette décision.

Toutes les règles générales du guide restent applicables.

---

# 2. Philosophie

Le rapport est un outil d'aide à la décision.

Il ne remplace pas le jugement de l'utilisateur.

Il fournit toutes les informations nécessaires pour :

* comprendre la décision ;
* vérifier les calculs ;
* identifier les hypothèses ;
* remettre en question les conclusions si les données évoluent.

Chaque affirmation doit pouvoir être justifiée.

---

# 3. Structure générale

Le rapport comprend notamment :

* résumé exécutif ;
* contexte de la mission ;
* données d'entrée ;
* analyse ;
* configuration retenue ;
* justification ;
* risques ;
* recommandations ;
* annexes techniques.

---

# 4. Résumé exécutif

Cette section présente :

* la configuration recommandée ;
* les principaux critères ayant conduit au choix ;
* les points forts ;
* les principales limites ;
* le niveau de confiance.

Cette section doit pouvoir être comprise sans lire le reste du rapport.

---

# 5. Contexte de la mission

Le rapport rappelle notamment :

* les usages principaux ;
* les usages secondaires ;
* les contraintes ;
* le budget ;
* les priorités utilisateur ;
* la stratégie retenue.

Cette section garantit que la décision est replacée dans son contexte.

---

# 6. Données utilisées

Le rapport distingue clairement :

## Données mesurées

Issues de mesures réelles.

---

## Données constructeur

Issues des spécifications officielles.

---

## Données calculées

Issues des métriques du moteur.

---

## Hypothèses

Informations supposées faute de données disponibles.

Chaque catégorie est identifiée explicitement.

---

# 7. Analyse de la configuration

Le rapport présente notamment :

## Compatibilités

Toutes les compatibilités vérifiées.

---

## Interactions

Les interactions importantes entre composants.

---

## Goulots d'étranglement

Les limitations identifiées.

---

## Marges

Les réserves disponibles :

* thermiques ;
* électriques ;
* budgétaires ;
* évolutives.

---

## Équilibre global

Analyse qualitative de la cohérence du système.

---

# 8. Justification des choix

Pour chaque composant retenu, le rapport explique :

* pourquoi il a été sélectionné ;
* quels critères ont été déterminants ;
* quels compromis ont été réalisés ;
* quelles alternatives ont été écartées.

Chaque choix doit être argumenté.

---

# 9. Profils de scores

Le rapport présente les différents profils calculés.

Exemples :

* technique ;
* économique ;
* énergétique ;
* thermique ;
* robustesse ;
* évolutivité ;
* maintenabilité ;
* ergonomie.

Chaque score est accompagné de son interprétation.

---

# 10. Analyse des risques

Le rapport identifie notamment :

* les risques techniques ;
* les risques économiques ;
* les risques d'évolution ;
* les risques liés aux hypothèses ;
* les incertitudes.

Chaque risque est qualifié selon :

* sa probabilité ;
* son impact ;
* les moyens de mitigation.

---

# 11. Analyse de sensibilité

Le rapport indique notamment :

* ce qui changerait avec un budget différent ;
* l'impact d'une évolution des usages ;
* les composants les plus sensibles ;
* les décisions les plus robustes.

Cette section met en évidence la stabilité de la recommandation.

---

# 12. Recommandations

Le rapport peut proposer :

* des variantes moins coûteuses ;
* des variantes plus performantes ;
* des évolutions futures ;
* des améliorations prioritaires.

Chaque recommandation est justifiée.

---

# 13. Traçabilité

Le rapport conserve notamment :

* les données d'entrée ;
* les métriques calculées ;
* les pondérations ;
* les décisions intermédiaires ;
* les hypothèses.

Une décision doit pouvoir être reproduite à partir du rapport.

---

# 14. Annexes techniques

Les annexes peuvent contenir notamment :

* mesures détaillées ;
* métriques complètes ;
* tableaux comparatifs ;
* calculs intermédiaires ;
* références des sources.

Les annexes permettent d'auditer la décision sans alourdir la lecture principale.

---

# 15. Principe final

Le rapport constitue la mémoire du processus de décision.

Il ne se contente pas de présenter une recommandation.

Il expose les faits, les analyses, les compromis, les limites et les justifications ayant conduit à cette recommandation.

Son objectif est de permettre à toute personne disposant des mêmes données de comprendre, de reproduire et, si nécessaire, de remettre en question la décision prise.

La qualité d'un rapport ne se mesure pas à sa longueur, mais à sa capacité à rendre le raisonnement transparent, vérifiable et exploitable.
