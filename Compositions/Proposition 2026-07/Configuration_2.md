# Configuration 2 — Liste de courses (Value durable)

> **Objectif :**
>
> Construire la configuration offrant le meilleur **rapport valeur / longévité / coût**.
>
> Cette machine accepte volontairement un léger compromis sur les performances GPU immédiates afin de :
>
> - maximiser la réserve budgétaire ;
> - limiter l'exposition au marché 2026 ;
> - préparer un upgrade GPU futur lorsque les prix seront redevenus raisonnables.
>
> La philosophie est simple :
>
> **Ne pas acheter aujourd'hui ce qui sera beaucoup moins cher demain si cela n'apporte pas un gain proportionnel.**

# Philosophie de cette configuration

Cette configuration cherche à maximiser le **retour sur investissement**.

Elle considère que :

- le Ryzen 9 9950X3D restera excellent pendant de nombreuses années ;
- 64 Go de RAM répondent pleinement aux besoins de la mission ;
- une RTX 5070 Ti est largement suffisante aujourd'hui en 4K avec DLSS 4.

L'argent économisé est volontairement conservé afin de financer un futur GPU lorsque :

- les prix auront baissé ;
- les RTX 60xx seront disponibles ;
- ou un éventuel refresh RTX 50 Super deviendra intéressant.

Autrement dit :

> **On achète aujourd'hui uniquement ce qui apporte un gain réellement rentable.**
