# Philosophie de cette configuration

Cette machine est construite autour d'un principe simple :

> **Le GPU est l'investissement principal.**

La RTX 5090 représente ici l'élément le plus important du système.

Le reste de la configuration est organisé pour lui permettre de s'exprimer pleinement, même si cela implique quelques compromis temporaires.

Le principal compromis concerne la mémoire :

- 32 Go au départ ;
- remplacement futur par 64 Go (2 × 32 Go) lorsque les prix auront retrouvé un niveau plus raisonnable.

Cette stratégie permet de bénéficier immédiatement :

- des 32 Go de VRAM ;
- des performances CUDA maximales ;
- d'une durée de vie GPU exceptionnelle.

Elle est particulièrement adaptée aux utilisateurs dont les projets Blender, IA ou vidéo sont suffisamment lourds pour que la VRAM devienne le facteur limitant avant la puissance de calcul.
