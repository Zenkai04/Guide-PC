# Configuration 4 — Liste de courses (Silence & Sobriété)

> **Objectif :**
>
> Construire une machine extrêmement performante tout en privilégiant :
>
> - le silence,
> - les faibles températures,
> - la faible consommation,
> - la stabilité,
> - la longévité,
> - le confort d'utilisation.
>
> Cette configuration ne cherche pas le benchmark maximal.
>
> Elle cherche à construire un ordinateur capable de fonctionner plusieurs heures par jour pendant de nombreuses années sans devenir une source de bruit ou de chaleur.
>
> **Philosophie :**
>
> > Une machine performante est agréable.
> >
> > Une machine silencieuse est invisible.

# Philosophie de cette configuration

Cette machine est conçue pour disparaître.

L'utilisateur ne doit plus penser :

- au bruit,
- aux températures,
- à la consommation,
- aux vibrations.

Chaque composant est choisi pour améliorer le confort quotidien.

L'undervolting léger du processeur et de la carte graphique permet de réduire fortement :

- la consommation électrique ;
- les températures ;
- le bruit.

Tout cela sans perte de performances perceptible dans les usages réels.

Cette configuration est idéale pour les développeurs, créateurs ou joueurs qui passent plusieurs heures par jour devant leur ordinateur et considèrent que le silence est une véritable caractéristique de qualité.
