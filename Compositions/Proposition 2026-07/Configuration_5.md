# Configuration 5 — Liste de courses (Performance Maximale)

> **Objectif :**
>
> Construire une machine sans compromis, visant uniquement les meilleures performances possibles.
>
> Cette configuration cherche à maximiser :
>
> - les performances CPU ;
> - les performances GPU ;
> - la bande passante mémoire ;
> - la capacité de stockage ;
> - la connectivité ;
> - la capacité d'évolution.
>
> Les critères de coût, de consommation électrique et de rapport performances/prix deviennent secondaires.
>
> **Philosophie :**
>
> > Si une amélioration apporte un gain mesurable, elle est retenue, même si son coût est élevé.

# Philosophie de cette configuration

Cette machine représente le sommet de la plateforme grand public.

Chaque composant est choisi pour offrir :

- les meilleures performances disponibles ;
- une excellente évolutivité ;
- une capacité de travail importante ;
- une grande réserve de puissance pour les années à venir.

Elle ne cherche pas le meilleur rapport qualité/prix.

Elle cherche à supprimer tous les goulots d'étranglement identifiables.

Les compromis concernent uniquement les limites actuelles de la plateforme AM5.
