# Boîtier

## 1. Objet

Ce document définit les règles de sélection du boîtier.

Le boîtier constitue l'environnement physique du système informatique.

Il assure :

* l'intégration mécanique des composants ;
* la circulation de l'air ;
* la protection physique ;
* la gestion des câbles ;
* l'accessibilité pour la maintenance ;
* une partie des performances acoustiques.

Sa sélection influence directement :

* les performances thermiques ;
* le niveau sonore ;
* la facilité d'assemblage ;
* les possibilités d'évolution ;
* la durabilité du système.

Toutes les règles générales du guide restent applicables.

---

# 2. Mission

La mission du boîtier est de fournir un environnement mécanique, thermique et fonctionnel permettant à l'ensemble des composants de fonctionner durablement dans de bonnes conditions.

Le boîtier ne produit aucune ressource informatique.

Il facilite le fonctionnement de toutes les autres.

---

# 3. Ressources fournies

## Volume interne

Espace disponible pour accueillir les composants.

---

## Gestion des flux d'air

Organisation de la circulation de l'air :

* admission ;
* extraction ;
* séparation des flux.

---

## Protection

Protection contre :

* les chocs ;
* la poussière ;
* les contacts accidentels.

---

## Gestion des câbles

Chemins permettant :

* le passage ;
* la fixation ;
* la dissimulation des câbles.

---

## Modularité

Capacité à accueillir différentes configurations.

---

## Isolation acoustique

Réduction des nuisances sonores lorsque présente.

---

# 4. Capacités offertes

Le boîtier peut permettre notamment :

* l'installation de composants volumineux ;
* l'ajout de nouveaux disques ;
* l'installation de plusieurs ventilateurs ;
* l'installation de radiateurs AIO ;
* une maintenance simplifiée ;
* une meilleure circulation d'air ;
* un fonctionnement plus silencieux.

Ces capacités dépendent de l'architecture interne du boîtier.

# 6. Critères éliminatoires

Le boîtier est rejeté immédiatement si :

## Compatibilité

* carte mère incompatible ;
* GPU incompatible ;
* ventirad incompatible ;
* alimentation incompatible.

---

## Ventilation

* capacité insuffisante pour la mission.

---

## Contraintes

* coût supérieur au budget sans justification ;
* indisponibilité.

---

# 11. Critères de décision

Le boîtier est sélectionné selon :

1. compatibilité ;
2. performances thermiques ;
3. facilité de maintenance ;
4. évolutivité ;
5. qualité de fabrication ;
6. niveau sonore ;
7. coût.

Le moteur privilégie un environnement favorable au fonctionnement durable de la configuration plutôt qu'un design uniquement esthétique.

---

# 12. Durée de vie

Le moteur évalue notamment :

* qualité des matériaux ;
* possibilité d'accueillir de futurs composants ;
* facilité de remplacement des ventilateurs ;
* disponibilité des pièces détachées ;
* réutilisation dans une future configuration.

---

# 13. Risques

Les principaux risques sont :

* ventilation insuffisante ;
* incompatibilité mécanique ;
* bruit excessif ;
* accumulation de poussière ;
* difficultés de maintenance ;
* espace insuffisant pour les évolutions futures.

Chaque risque doit être documenté.

---

# 14. Rapport de décision

Le rapport final doit expliquer :

* pourquoi ce boîtier a été retenu ;
* comment il répond aux contraintes mécaniques et thermiques ;
* quelles possibilités d'évolution il offre ;
* quelles limites subsistent ;
* quelles mesures ont été utilisées ;
* quelles métriques ont été calculées ;
* quelles hypothèses ont été retenues.

La décision doit être entièrement traçable et reproductible.
